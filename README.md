# qyekq

企业微信上下班提醒。到点给启用的人发应用消息。已经打卡或当天请假的人跳过。

## 环境

- Python 3.12
- 可选：Redis。连不上时令牌和调度锁记在当前进程里，重启后重新取

## 配置

在项目根目录放 `.env`。这个文件不会提交。

```text
QYEBOT_REDIS_URL=redis://127.0.0.1:6379/0
QYEBOT_DB_PATH=data/qyebot.sqlite
QYEKQ_USER=运营账号
QYEKQ_PASSWORD=自行设置
```

Redis 只有密码时写成 `redis://:密码@主机:6379/0`。有账号和密码时写成 `redis://账号:密码@主机:6379/0`。密码里如果有 `@`、`:`、`/`、`#`，要先做 URL 编码。改完 `.env` 后重启 `run.py`。

`QYEKQ_USER` 和 `QYEKQ_PASSWORD` 写在本机 `.env` 里。两项都有值，而且库里还没有登录账号时，第一次启动才会创建运营账号。缺任何一项都不会创建，也不会使用内置默认账号。库里已经有账号之后，再改这两项不会替换旧密码。

相对路径的数据库文件按项目根目录解析。

## 安装和启动

```text
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.venv\Scripts\python.exe run.py
```

Linux 上把 `.venv\Scripts\python.exe` 换成 `.venv/bin/python`。

浏览器打开 http://127.0.0.1:8787

`run.py` 只监听 `127.0.0.1:8787`。要用别的机器访问，把其中的 host 改成 `0.0.0.0`。

## 登录

第一次启动读取 `.env` 里的 `QYEKQ_USER` 和 `QYEKQ_PASSWORD` 建立登录账号。两项都要有值。库里已经有账号时不会覆盖。

未登录时，提醒、人员、班次、记录、连接都会停在登录页。登录状态写在 HttpOnly Cookie `qyekq_session` 里，页面脚本读不到。记住登录保留 14 天，否则保留到浏览器关闭。

提交登录时，页面先向 `/api/auth/salt` 取盐和一次性随机数，再用 PBKDF2 和这个随机数生成证明后提交。请求里没有明文密码，这条证明也不能重复使用。退出登录会作废当前会话。连续输错 5 次会停 1 分钟。

## 企业微信

在「连接」页填写企业 ID、AgentId、Secret，然后点测试连接。Secret 只存在本机 SQLite，接口只返回末四位。

自建应用需要：

- 发送应用消息
- 打卡：配置到「打卡 - 可调用接口的应用」。用来跳过已经打卡的人
- 审批：配置到「审批 - 可调用接口的应用」。用来读取请假审批单
- 通讯录读取：只在需要从企业微信同步人员时使用
- 服务器出口 IP 加入企业微信可信 IP

不拷数据库就在新机器的连接页重新填写。拷贝 `data/qyebot.sqlite` 时，连接信息和登录账号会一起过去。

## 页面

- 提醒：规则列表。每条规则有上班或下班、提前或延后的分钟数、接收人。右上角新增提醒
- 人员：添加时从本地缓存的企业微信成员里选。缓存每天按「连接」页的同步时间自动刷新一次。点「同步企业微信成员」会立刻向企业微信要一份新名单。可单独停用
- 班次：上下班时间和星期。放假、补班按日期手工添加。标成放假的日期不发；标成补班的日期照常发。系统不会自动拉取法定节假日
- 记录：已发送、已跳过、失败。每页 20、50 或 100 条，可以翻页
- 连接：企业微信凭证和测试消息

同一人、同一规则、同一时点只发一次。

## 请假

请假同步时间在「连接」页配置，按上海时间每天到点拉一次。没填过时是 06:30。还没到当天这个时刻时不会拉，包括第一次。到点后第一次会补近 28 天，之后只拉上次成功时间之后的新单，并重叠 2 分钟。本地只保留近 28 天。今天这个时刻已经过了、而且今天还没拉取过时，保存后下一轮检查就会拉取。

用的接口：

- `POST /cgi-bin/oa/getapprovalinfo`
- `POST /cgi-bin/oa/getapprovaldetail`

只认标准请假控件（`Vacation`，类型为请假）且状态为已通过的单。驳回、撤销、通过后撤销会从本地去掉。

到点时用请假的起止时间对照上下班时刻。落在区间内就跳过，记录写「当天请假」。当天同步时刻之后才审批通过的假，要到下一次同步才进本地。审批接口失败时停 30 分钟再试，不打断发提醒。

## 令牌

企业微信 `access_token` 缓存在 Redis 键 `qyebot:token:{企业ID}`。有效期使用接口返回的 `expires_in` 再提前 200 秒。缓存没有或令牌失效时才重新拉取。Redis 不可用时，同一套有效期记在当前进程内存里。
